# AI Disclosure

## 1. Tools used

- **Claude Code** (Anthropic, Claude Opus 5.5 model), used in the VS Code extension.

## 2. Per-item prompts for PromQL, regex and Alertmanager

The prompts below are written per item: each one, given to Claude Code, produces that query, regex or config.

### 2.1 Regex

| Where                                               | Regex                                                                       | Prompt                                                                                                                                                                                                |
| --------------------------------------------------- | --------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `prometheus/prometheus.yml` (node job relabel)      | `([^:]+):\d+` → `instance="host"`                                           | "Add a relabel rule to the node_exporter scrape job that matches the `host:port` address and replaces the `instance` label with `host`, so dashboard legends don't show `host.docker.internal:9100`." |
| `docker-compose.yml` (node_exporter flag)           | `^/(dev\|proc\|sys\|run\|var/lib/docker/.+)($\|/)`                          | "Write a regex for node_exporter's `--collector.filesystem.mount-points-exclude` that skips /dev, /proc, /sys, /run and Docker's internal mounts, so only real disks are reported."                   |
| `alert_rules.yml`, dashboard disk panel             | `fstype!~"tmpfs\|overlay\|squashfs"` (dashboard also `nsfs\|ramfs\|fuse.*`) | "Exclude virtual filesystems (tmpfs, overlay, squashfs, nsfs, ramfs, fuse) from the disk-usage query with a label regex matcher."                                                                     |
| Dashboard network panel                             | `device!~"lo\|docker.*\|br-.*\|veth.*"`                                     | "Filter the network rx/tx query to physical interfaces only: drop loopback, docker0, bridge and veth devices with a regex."                                                                           |
| `grafana/build_dashboard.py` (`byRegexp` overrides) | `/<series name>/`                                                           | "Add a Grafana field override that matches series by display-name regex so I can give the 'failed', 'p99', 'CPU' etc. series their own colour and line style."                                        |

### 2.2 PromQL: alert rules (`prometheus/alert_rules.yml`)

| Alert                   | PromQL                                                                                      | Prompt                                                                                                                                        |
| ----------------------- | ------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------- |
| CaptionAppDown          | `up{job="caption-app"} == 0` for 30s                                                        | "Write a critical alert that fires when Prometheus cannot scrape the caption-app /metrics endpoint for 30 seconds."                           |
| CaptionModelNotLoaded   | `caption_model_loaded == 0` for 2m                                                          | "Alert (warning) when the app is up but the `caption_model_loaded` gauge is still 0 after 2 minutes."                                         |
| HighInferenceLatencyP95 | `histogram_quantile(0.95, sum by (le) (rate(caption_inference_seconds_bucket[5m]))) > 5`    | "Using the `caption_inference_seconds` histogram, alert when the p95 per-image inference latency over 5 minutes is above 5 seconds."          |
| HighCaptionErrorRatio   | `sum(rate(...{status="error"}[5m])) / sum(rate(caption_images_processed_total[5m])) > 0.10` | "Alert when more than 10 % of processed images failed in the last 5 minutes, using `caption_images_processed_total` with the `status` label." |
| CaptionQueueBacklog     | `histogram_quantile(0.95, sum by (le) (rate(caption_queue_wait_seconds_bucket[5m]))) > 10`  | "Add an info alert when the p95 time requests wait for the model lock exceeds 10 seconds, meaning concurrent users are queueing."             |
| NodeExporterDown        | `up{job="node"} == 0` for 30s                                                               | "Critical alert when node_exporter has not been scraped for 30 seconds."                                                                      |
| HostHighCpu             | `100 * (1 - avg by (instance) (rate(node_cpu_seconds_total{mode="idle"}[1m]))) > 90`        | "Alert when host CPU busy % (100 minus idle %, averaged over cores) stays above 90 % for 2 minutes."                                          |
| HostLowMemory           | `100 * node_memory_MemAvailable_bytes / node_memory_MemTotal_bytes < 10`                    | "Alert when less than 10 % of host RAM is available for 2 minutes."                                                                           |
| HostDiskAlmostFull      | `100 * node_filesystem_avail_bytes{...} / node_filesystem_size_bytes{...} < 10`             | "Alert when any real (non-tmpfs/overlay) filesystem has less than 10 % free space for 5 minutes, showing the mountpoint."                     |

### 2.4 Alertmanager (`alertmanager/alertmanager.yml`, `alertmanager/alert_logger.py`)

**Prompt:** "Set up Alertmanager for the Prometheus alert rules: group notifications by alertname and severity (10 s group wait, 30 s group interval, 1 h repeat), send critical alerts immediately with no group wait, and deliver everything (including resolved notifications) to a webhook. Write a small Python webhook receiver container that prints each alert's status, name, severity, summary and start time to its logs. Add an inhibit rule so that when CaptionAppDown fires, the model-not-loaded, latency, error-ratio and queue-backlog alerts are suppressed."
